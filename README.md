# Play Equity Report Project Map

Interactive project map for the **King County Play Equity Coalition** Play Equity Report · Built by [The Data Guys™](https://www.thedataguys.org)

[![Live map](https://img.shields.io/badge/live%20map-open-3FB8AF?style=for-the-badge)](https://dthedataguy.github.io/kcpec-play-equity-map/)

One place for partners to review the report's deliverables, content, data, decisions, hosting and timeline.

## What's inside

- **Everything in one place:** deliverables and content at a glance
- **The 8 Play Equity domains:** source fit, where each domain lives on the web, open questions and a tracker
- **Who owes what, and when:** owners and due dates
- **From first call to community launch:** the project timeline
- **From UW's inputs to what people see:** how source data flows into the published report

Mappings and decisions shown on the map are working drafts for partner review. Checkmarks are saved in your own browser only and are not shared team progress.

## Run it locally

Static HTML, CSS and JavaScript with no build step. Project content lives in [`data.js`](data.js).

```bash
git clone https://github.com/DTheDataGuy/kcpec-play-equity-map
cd kcpec-play-equity-map
python3 -m http.server 8000   # then open http://localhost:8000
```
